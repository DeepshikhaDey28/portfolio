# Starville: The Midnight Broadcast

Point-and-click mystery. Open this folder in VS Code and either:
- install the Live Server extension, right-click index.html, Open with Live Server; or
- run `python -m http.server 8000` here and open http://localhost:8000

standalone/starville.html is the same game as one self-contained file (double-click to play).

Controls: click = use/take/walk, right-click = inspect, Shift+click = talk, M = map, H = hint, Esc = menu.
Fonts load from Google Fonts (needs internet for the pixel look).
Code: game.js. Styles: style.css. Images/audio: assets/.
